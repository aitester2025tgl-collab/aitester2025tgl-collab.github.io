01 / The idea

Make complex AI workflows feel simple.

Personagem Processor PRO is a local GUI designed to automate and accelerate the creation of consistent character sprites for Visual Novels.

The application acts as a layer between the user and a local ComfyUI server, hiding the complexity of nodes and workflows behind menus, controls and dedicated creative tasks.

The interesting product challenge was not simply generating an image. It was making a powerful but complex workflow easier to operate repeatedly when building a character.

02 / What it does

One character.
Many possibilities.

The tool brings several character-generation and image-preparation workflows into one local interface.

01

Create

Generate new characters using combinations of camera angles, artistic styles, clothing and other character attributes.

02

Keep consistency

Use FaceID-based workflows to preserve a character's facial identity from a reference image.

03

Edit

Modify clothing, colours or style while keeping the original anatomy through ControlNet-based workflows.

04

Expand & express

Turn portraits into fuller character images or change expressions while preserving the rest of the character.

05

Prepare sprites

Remove backgrounds and prepare images for Visual Novel sprite dimensions, including batch processing.

06

Iterate

Reuse workflows, generate alternatives with new seeds, keep a local history and compare results before and after edits.

04 / The product layer

Not just image generation. A usable tool.

The underlying technology can be powerful and still be difficult to use. This project explores what happens when the workflow is treated as a product problem rather than just a technical one.

COMPLEXITYComfyUI · Nodes · Workflows · Models
PRODUCT LAYERMenus · Parameters · Preview · History

The result is a dedicated interface that hides much of the technical complexity while keeping the creative controls accessible.

05 / Technical foundation

A local AI stack behind the interface.

The README describes a modular Python application that communicates with a local ComfyUI server and coordinates image-processing and generation workflows.

Python + Tkinter

Native desktop interface and application logic.

ComfyUI

Local diffusion engine for SDXL / Pony workflows.

ControlNet

Lineart and OpenPose workflows for controlled edits and expression changes.

IP-Adapter / FaceID

Reference-based facial consistency with InsightFace.

Rembg

Automatic background removal and sprite preparation.

06 / What I explored

The real experiment was the workflow.

This project was an exploration of how a complex AI stack can be turned into a focused tool for a specific creative workflow.

Instead of exposing the underlying technical setup directly, the product is organised around the decisions a user actually wants to make: what to create, what to change, what to preserve and how to prepare the result.

For me, that is the interesting part of the project: using AI capabilities as building blocks for a product rather than treating the model itself as the product.

07 / Current status

A personal tool built for experimentation.

Personagem Processor PRO is a personal and experimental project, built for local use and exploration of AI-assisted creative workflows.
